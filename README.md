# SKY TILT — スマホを傾けて飛ぶ 3D フライトゲーム

スマートフォンを横向きに持ち、端末の傾きで操縦する Web ゲームです（Vite + 素の JavaScript + three.js）。
12 機体 × 5 ロケーション × 4 時間帯 × 3 天候。フリーフライト / リングコース / 射撃 / 着陸チャレンジ、2 人同時プレイ（P2P）。

- 小型プロペラ機 / 旅客機（FBW 保護）/ 戦闘機（A/B・G メーター・追尾ミサイル）/ グライダー / ヘリコプター / FPV ドローン / 空飛ぶスポーツカー（走行 ⇄ 飛行）/ 熱気球 / パラグライダー / ジェットスーツ / ウイングスーツ / スカイダイビング
- 海と島（滑走路）/ 山岳・渓谷 / 高層ビルの都市 / 砂漠・キャニオン（未舗装滑走路）/ 雪山

## 遊び方

1. **スマホを横向き**にしてページを開き、「タップしてスタート」。iPhone では傾きセンサーの許可ダイアログが出るので「許可」。
2. 機体を選ぶ（カードの棒グラフ: 速度・機動性・難易度）→「次へ」。
3. ロケーション・時間帯・天候・モードを選んで「飛行開始」。
4. **飛行開始時の持ち方がニュートラル**になります。手前に少し傾けた楽な姿勢で構えてください。持ち方を変えたら左上の **⟲** で再キャリブレーション。

| 操作 | 傾き（既定） | 画面 |
|---|---|---|
| 旋回（ロール） | 左右に傾ける（ハンドルのように） | — |
| 機首上げ / 下げ | 画面の上端を手前に引く / 奥へ倒す | — |
| 出力（スロットル / コレクティブ / 推力） | — | 右手側の縦スライダーをドラッグ |
| 機体固有の操作 | — | 左手側のボタン（ラダー、フラップ、ギア、スポイラー、A/B、テールロータ、パラシュート） |
| 一時停止・設定・機体変更 | — | 左上 ❚❚ |
| 視点（後方追従 / コックピット / 外部） | — | 右上「視点」 |
| 早送り ×2 / ×4（熱気球・パラグライダー・グライダー） | — | 右上「▶×1」 |
| 射撃・ミサイル（射撃モード） | — | 右手側・スロットルの左の赤いボタン（押している間撃つ） |
| 操作ガイド | — | タイトル・機体選択・一時停止メニューの「📖 操作ガイド」 |
| オートパイロット（高度と方位を保つ） | — | 右上「AP」 |

- 傾きセンサーが使えない端末・許可しなかった場合は、**左下のバーチャルスティック**に自動で切り替わります（設定で手動切替も可）。
- 機体ごとのコツ
  - **プロペラ機**: スロットル全開で滑走、約 90 km/h で手前に引くと機首が上がり、約 110 km/h で浮く。手を戻すと水平に戻る練習機。
  - **旅客機**: バンク 67°・ピッチ +30°/−15° の保護と失速保護付き。着陸はフラップ FULL・ギア DOWN で。
  - **戦闘機**: A/B で急加速。9G 制限。強く引き続けると視界が暗くなる。低速で引きすぎると失速、離せば回復。
  - **ヘリ**: スライダー＝コレクティブ（上下）、傾き＝サイクリック（傾いた方向へ進む）、ボタン＝向き。地面近くは地面効果で浮きやすい。
  - **パラグライダー**: 推力なし。左右＝片側ブレーク、手前＝両ブレーク、奥＝スピードバー。斜面の風上側（斜面上昇風）や積雲の下（サーマル）で上昇、上昇中はバリオ音。
  - **ジェットスーツ**: 前に傾けると推力が前を向いて巡航。燃料ゲージに注意。
  - **ウイングスーツ**: 手前で滑空比重視、奥で高速。最後は「パラシュート」。
  - **スカイダイビング**: 奥に倒すとトラッキング（水平移動）。「パラシュート」で展開、キャノピーは左右で旋回・手前でフレア。目標の同心円にどれだけ近く降りられるかがスコア。
  - **グライダー**: エンジンなし、滑空比 37。手を離すと約 105 km/h の最良滑空速度に落ち着く。サーマル（積雲の下）で小さく旋回して上昇。
  - **ドローン**: 機敏なクアッドコプター。約 33% でホバリング。「視点」でコックピット（FPV）にするとレース気分。
  - **空飛ぶ車**: 走行中は左右でハンドル・手前でブレーキ（止まってさらに 1 秒保つと後退）。「飛行 ⇄ 走行」で 4 つのファンが開いて離陸。着地してから走行に戻る。ビルの屋上にも降りて走れ、縁から走り出ると飛び出す。
  - **ドリフトクーペ**: 後輪駆動。ドリフトの練習に最適。
  - **ラリーカー**: 四輪駆動で砂利・雪に強い。ジャンプも得意。
  - **ハイパーカー**: 最高時速 400 km 近く。空力で高速コーナーに強いがブレーキは早めに。
  - **モンスター**: 巨大タイヤ。草地や砂でも舗装と同じように走れ、1.2 m の段差を越える。
  - **カート**: 軽くて小回り抜群。
  - **ホバーカー**: 浮いて走るので水の上も行ける。氷の上のように滑る。
  - **熱気球**: 操縦は高さだけ。バーナーで上昇、排気弁で降下。高さによって風向きが違う（HUD に ±300 m の風）ので、行きたい方向の風の高さへ。
- **リングコース**: 番号付きのリングを順にくぐる。次のリングには画面上の円（緑＝このまま進めば通れる／橙＝ずれている）と、距離・到達までの秒数・高さの差が出る。リングから地面へ下りる支柱と地面の影、次のリング以降をつなぐ点線、右上のレーダーも目安に。自己ベストは半透明の「ゴースト」で再生。
- **射撃**: 風船・地上の的・敵機（3 波）を撃ち落とす。白い照準の近くにある的には自動で狙いを補正し、黄色の点（偏差照準＝目標の未来位置）へ弾が飛ぶ。戦闘機は敵を正面の円に約 1 秒入れ続けるとロックオン →「ミサイル」。武器の無い機体は風船に体当たり（的は機体の飛び方に合わせて、滑空系なら滑空で届く通り道に並ぶ）。被弾すると体力が減り、0 で撃墜。撃たれた方向は画面中央の赤い弧、狙われると警告。パラグライダーなど飛び直せない機体は、着地した時点の点数で終了。難易度は設定で。
- **設定**: 操作方式・感度など、音量・振動、レーダー・ゴースト、画質、難易度（射撃とレース）、左利き配置、ボタンの大きさ、HUD の濃さ、カメラの距離、車のアシスト（強・中・切）、アクセル（ボタン・傾き・自動）、ハンドル（傾き・◀▶）、ハンドル感度。
- **車の運転**: ハンドルは傾き（またはスティック、設定で ◀▶ ボタン）。右の「アクセル」「ブレーキ」（設定で傾き・自動にも変更可）。止まってからブレーキを押し続けるとバック。
  - **ドリフト**: 曲がりながら左の「サイド」を一瞬押す → アクセルを踏んだまま傾きで滑る角度を調整 → 傾きを戻すと収まる。
  - **ニトロ**: 押している間だけ加速。ドリフト中によくたまる。**復帰**: 立ち往生したら少し前の場所へ。壁に当たっても墜落せず、水に落ちても戻る。
  - **路面**: 舗装 > ダート > 草地 > 砂 > 雪 > 氷 の順に滑る。雨・雪の日はさらに滑る。
- **レース**: ライバル 3 台と周回。緑のゲートを順に通る。自己ベストはゴーストで再生。 **ドリフト**: 90 秒で点数を稼ぐ（角度×速さ、続けると最大 ×5）。 **駐車**: 黄色い枠に止める（3 か所、位置と向きで採点）。
- **便利な機能**: 🎓 練習（操作しながら覚える）、📅 今日のチャレンジ、🏆 記録と実績（22 種類）、🎬 リプレイ（結果画面）、📷 写真（一時停止メニュー）、着陸モードの進入ガイド（緑の線を中心へ）、地形の警告。
- 墜落するとリトライ画面。着陸に成功すると、接地速度・降下率（と精度）で S/A/B/C 評価。
- PC デバッグ用キーボード: W/S/↑/↓ ピッチ、A/D/←/→ ロール、Q/E ヨー、Shift/Ctrl スロットル、F フラップ、G ギア、X スポイラー、B アフターバーナー、Space パラシュート、T 飛行⇄走行、K/Enter 射撃、M ミサイル、H/J バーナー/排気弁、C 視点、R 再キャリブレーション、Y 早送り、L オートパイロット、Esc 一時停止。車: W/S アクセル・ブレーキ、A/D ハンドル、Space サイド、N ニトロ、V 復帰。
- ゲームパッド（標準配列）: 左スティック＝姿勢、右スティック上下＝スロットル、LB/RB＝ヨー、A/RT＝射撃・バーナー、LT＝排気弁、B＝ラダー以外の最初の機体ボタン、X＝ミサイル、Y＝視点、Back＝早送り、Start＝一時停止。車: RT/LT＝アクセル・ブレーキ（アナログ）、A＝サイド、X＝ニトロ。
- ホーム画面に追加（PWA）すると全画面で起動し、一度遊んだ後はオフラインでも動きます。

### 2 人で飛ぶ

1. 2 人ともタイトルの「👥 2人で飛ぶ」。
2. 1 人が「ルームを作る」→ 表示される 4 文字のコードを相手に伝える。相手はコードを入れて「参加」。
3. 「機体を選ぶ」→ それぞれ好きな機体を選ぶ。ゲストは待機、ホストが場所・時間帯・天候・モード（フリー / リング競争 / 射撃）を選んで開始。
4. 相手は名札付きで見え、画面外のときは矢印と距離、レーダーに水色の点で出ます。リングは同じコース（遅い方の機体に合わせたコース・大きい方の輪）で競争、射撃では同じ配置の風船の取り合いと撃ち合い（撃墜 +1000 点）。ホストが「もう一度」を押すと 2 人ともやり直します。
5. レーダーの下に通信の往復時間が出ます。3 秒届かないと「通信が不安定です」、12 秒で切断扱いになります。

- 通信は端末どうしの直接通信（WebRTC）。ルームコードの受け渡しだけ PeerJS の公開サーバー（0.peerjs.com）を使います。サーバーに頼りたくないときは「サーバーなしで接続」で接続コードを 1 往復コピーし合えばつながります。
- 状態は 1 秒に 20 回送り、相手の表示は 0.1 秒前を補間して滑らかにしています。遅延は同じ Wi-Fi で数 ms〜20 ms、モバイル回線同士で 50〜150 ms 程度が目安で、操作の手応えは自分の端末で計算するので遅れません。
- 一部のモバイル回線・企業ネットワーク（対称型 NAT）では直接つながらないことがあります（中継用の TURN サーバーは用意していません）。**いちばん確実で遅延も小さいのは、2 台を同じ Wi-Fi につなぐこと**です。「ルームは見つかりましたが直接つながりませんでした」と出たら、同じ Wi-Fi にするか、「サーバーなしで接続」を試してください。

## 操縦感の調整（パラメータの場所と意味）

### 入力（`src/input/pipeline.js`、ゲーム内の「設定」でも変更可）
| 名前 | 既定 | 意味 |
|---|---|---|
| `smoothing` | 0.08 s | ローパスの時定数。大きいほど滑らかだが遅れる |
| `deadzone` | 2.0° | この角度以内の傾きは無視（手ぶれ対策） |
| `sensitivity` | 1.0 | 倍率。1.0 でピッチ 25°・ロール 30°（`FULL_SCALE_DEG`）でフル入力 |
| `expo` | 0.35 | 0=線形。大きいほど中央付近が鈍く、端で鋭い（y=(1-e)x+ex³） |
| `invertPitch` | false | ピッチ反転 |
| `FULL_SCALE_DEG` | pitch 25 / roll 30 | フル入力になる傾き角（感度 1.0 のとき） |

傾きの分解: ロール＝画面の面内でハンドルのように回した角度、ピッチ＝画面の上端を手前に引いた / 奥に倒した角度。どちらも重力基準なので、体の向き（方位）を変えても入力は変わりません。

傾きの計算（クォータニオン、画面角補正、キャリブレーション）は `src/input/orientation.js`。

### 機体（`src/data/vehicles.js` — 機体はここに追加できる）
固定翼（`model: 'fixedwing'`）の主なパラメータ:
| キー | 意味 | 操縦感への影響 |
|---|---|---|
| `mass`, `S` | 質量 [kg]、翼面積 [m²] | 翼面荷重 → 失速速度・離陸速度 |
| `CL0`, `CLa`, `alphaStall` | 揚力係数（α=0）、揚力傾斜 [/rad]、失速迎角 | CLmax と失速の出方 |
| `CD0`, `k` | 有害抗力、誘導抗力係数 | 最高速度・滑空性能・旋回での減速 |
| `roll.maxRate`, `roll.tau` | 最大ロールレート、応答時定数 | 「キビキビ / もっさり」の最大の要因 |
| `roll.bankCmd`, `roll.bankGain` | （小型機のみ）フル入力で目標とするバンク角、そこへ寄せる速さ | 傾けたままでその角度の旋回を保ち、戻すと水平に戻る（初心者向け） |
| `roll.autoLevel` | 入力ゼロで水平へ戻る強さ（使う場合） | 安定感 |
| `pitch.tauAlpha`, `pitch.tauRate` | 迎角・ピッチレートの応答時定数 | 機首の反応の速さ・重さ |
| `pitch.alphaMaxCmd` | フルに引いたときの目標迎角 | 失速迎角より大きいと引きすぎで失速する |
| `pitch.turnComp` | 旋回中の自動当て舵（0〜1） | 1 なら傾けるだけで高度を保って旋回 |
| `gLimit` | G 制限（正/負） | 戦闘機 9G、旅客機 2.5G |
| `fbw` | バンク・ピッチ・失速保護（旅客機のみ） | `bankLimit` 67°、`bankNeutral` 33° など |
| `thrust` | `prop`（静止推力・パワー）/ `jet`（ミリタリー・A/B 推力） | 加速 |
| `ground.rotateSpeed`, `ground.rotateRate` | 機首が上がり始める速度、地上での機首上げ速さ | 離陸速度 |
| `ground.maxSink` | 墜落にならない最大降下率 | 着陸の難しさ |

ヘリ: `thrustMax`（最大推力）、`rotorRadius`（地面効果の効く高さ）、`inflowDamping`（上下の安定性）、`etl`（転移揚力）、`att.maxPitch/maxRoll/tau`（サイクリックの効き）、`yaw.maxRate`。
パラグライダー/キャノピー/ウイングスーツ: `CLtrim`（トリム速度）、`CLbrake`/`CLmax`、`CLbar`/`CLmin`、`CD0`/`k`（滑空比）、`bankMax`/`tauBank`（旋回の速さ）。
スカイダイビング: `freefall.CdA`（終端速度）、`CdAtrack`/`CLAtrack`（トラッキング）、`deployTime`、`aadAgl`。
ジェットスーツ: `thrustMax`、`burnTime`（燃料）、`att.maxPitch`（前傾できる角度）。
ドローン: ヘリと同じモデル（`model: 'heli'`）で `thrustMax`（推力重量比 3）、`att.tau`（機敏さ）、`battery.burnTime`。
グライダー: 固定翼モデルで `thrust.type: 'none'`、`pitch.trimCL`（手を離したときの速度＝最良滑空）と `pitch.speedHold`（その速度へ寄せる強さ）。
空飛ぶ車: `drive`（`force`・`power`＝加速と最高速度、`maxSteer`・`gripLat`＝曲がりやすさ、`brake`・`reverse`）と `fly`（`thrustMax`・`att`・`dragArea`）。
熱気球: `envelopeVolume`・`mass`（浮力）、`burnerHeat`・`heatLoss`・`ventRate`（温度の変わりやすさ＝反応の遅さ）、`windCoupling`。高さによる風向の変化は `src/sim/world.js` の `windVeerAt`。

### 車（`src/sim/vehicles/car.js`・各車の `drive`）
| キー | 意味 | 操縦感への影響 |
|---|---|---|
| `torque`, `power`, `gears`, `final`, `wheelR`, `rpmMax` | エンジンと変速（`gears` が無ければ `force`・`power` の一段） | 加速と最高速度 |
| `gripF`, `gripR` | 前後のグリップ（路面の μ に掛かる） | 後ろを小さくすると滑りやすい |
| `driveFront` | 前輪の駆動配分（0＝後輪駆動、0.45＝四輪駆動） | 後輪駆動ほどパワーで滑る |
| `maxSteer`, `steerTau` | 最大舵角、ハンドルの速さ | 小回りと敏感さ |
| `driftAngle`, `driftSpeed`, `driftYaw` | ドリフトアシストの最大の滑り角・速さの目安・向きを変える強さ | ドリフトの決まりやすさ |
| `offroad` | 未舗装の不利を減らす割合（0〜1） | ラリー・モンスターの強さ |
| `ClA`, `CdA` | ダウンフォースと空気抵抗 | 高速コーナーと最高速度 |
| `nitro` | ニトロの時間と加速 | |
路面の μ は同ファイルの `SURFACES`、雨雪の倍率は `locations.js` の `WEATHERS[].grip`、コースは `locations.js` の `track`（制御点・幅・ジャンプ台）と `src/sim/track.js`、モードは `src/sim/carModes.js`。

### 射撃（`src/sim/combat.js`・各機体の `weapon`）
`weapon`: `rate`（毎秒の発射数）、`speed`（弾速）、`damage`、`ammo`、`spread`（ばらつき）、戦闘機は `missiles`・`lockRange`・`lockCone`・`lockTime`。難易度ごとのエイムアシストの円錐（ふつう: 固定翼 5°、それ以外 10°）・敵の弾のばらつきと威力・敵の数は `combat.js` の `DIFFICULTY`、敵の出し方・速さは `_spawnWave` / `_updateEnemy`、的の置き方は `_makeTargets`。

### 2 人プレイ（`src/net/`）
`protocol.js` の `STATE_HZ`（送信頻度）、`interp.js` の `INTERP_DELAY`（表示の遅らせ幅。大きいほど滑らか・小さいほど新しい）と `MAX_EXTRAP`（途切れたときに予測で進める上限）、`session.js` の `SILENCE_WARN` / `SILENCE_CLOSE`（何も届かないとき「不安定」と出す・切断とみなすまでの秒数）。

### ロケーション（`src/data/locations.js`）
`generator`（地形の生成関数、`src/sim/terrainGen.js`）、`field`（滑走路 / 着陸エリア）、`windFrom`（風向）、`thermals`（サーマル数）、`clouds`、`cloudBase`、`palette`（色）。時間帯 `TIMES`・天候 `WEATHERS`（風速・乱気流・サーマル強度）も同じファイル。

### カメラ・演出
`src/render/effects.js`（`CameraRig`: 追従の時定数、FOV の広がり、揺れ）、機体ごとの視点位置は `vehicles.js` の `camera`。

```bash
npm install
```

```bash
npm run test:e2e
```

## 公開（GitHub Pages）

この作業フォルダには Git リモートが無いため、ワークフローを用意してあります（`.github/workflows/deploy.yml`: Vitest → build → `dist/` を Pages へ）。

1. GitHub で空のリポジトリを作成。
2. このフォルダで:
   ```bash
   git init
   ```
   ```bash
   git add -A
   ```
   ```bash
   git commit -m "SKY TILT"
   ```
   ```bash
   git branch -M main
   ```
   ```bash
   git remote add origin https://github.com/<ユーザー名>/<リポジトリ名>.git
   ```
   ```bash
   git push -u origin main
   ```
3. リポジトリの **Settings → Pages → Build and deployment → Source** を **GitHub Actions** にする。
4. Actions のデプロイ完了後、`https://<ユーザー名>.github.io/<リポジトリ名>/` で公開（HTTPS なので iOS の傾きセンサーも使えます）。

`vite.config.js` は `base: './'`（相対パス）なので、サブディレクトリ配信でもそのまま動きます。
1 ファイル版 `dist-single/index.html` は、任意の HTTPS ホスティングに置くだけでも動きます。
